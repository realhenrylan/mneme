## 4. 机制归因（伴生重放证据）

- 臂1/臂2 重放（阈值 0.015）：**重放拒答 0 例**——39 例全在 [0.015, 0.030)，
  与侦查一致；臂1 缺口 97 = 实测 97，臂2 缺口 91 = 实测 91（重放-实测一致性验证）；
- 臂2 缺口 91 例中：真值块在 fused 内 **75 例**（宽面 300）、零通道 16 例、
  其余为刀口/预算层（rank 中位 64 ≫ 刀口 25 与 select 20 硬顶）——**剩余缺口的
  主导层仍是融合排序**（真值块深度排名靠前者少），宽度/档位已触及能力边界；
- 多样性（每源 3）非缺口主因（管道模拟 C 配置 = B 配置）。

## 5. 预算披露（如实）

- 已批上界：150 万 token（Q-M4b-3）
- 实耗：臂1 578,255 + 臂2 1,180,703 + judge 72,521 = **1,831,479**（**超 22%**）
- 超支原因：V3 上下文扩容（25 块/例）使 prompt 从 ~3k 升至 ~7k+ token/例，
  M4b §四的成本表按「75-90 万」预估偏低——**超支属变量本身成本**，非失控。

## 6. 判定结论

- **P1 = 0.7459 > 0.50 ⇒ `FAIL`**（M4 §七：归档病理、不回退判据、owner 重决策）。
- **但产品侧信号为净进步**：修正率 0.4397 → **0.5575**（答案语义命中+0.118，
  主要来自 39 例早退放行后的真实生成 + judge 面命中 74 vs 53）、误拒率
  0.393 → **0.139**、citation recall 0.032 → **0.046**、faithfulness 0.541 → 0.604；
  代价面为探针拒答正确率 0.393 → 0.179（5 例哨兵→错误回答）与 token 成本
  +315%（1.18M vs 0.44M）。

## 7. 病理与 owner 重决策选项（M4 §七）
