## 一、背景：两轮基线暴露的关键事实（既成事实，非本提案观测结果）

| 维度 | 基线值 | 说明 |
| --- | --- | --- |
| 检索缺口率（可答例 122） | **99/122 = 0.8115** | context∩truth=∅；答案引用质量的主要制约是检索未召回真值块，而非引用错位 |
| 拒答正确率（探针 28） | **11/28 = 0.3929** | 语义式陈述占探针 17/28（非消息形态） |

| judge 契约错误率 | **0.0390**（6/154，均耗时 3 次重试） | judge 协议 `al2-judge-v1` 可信可用 |

**因果结构判断（一次只能改一个变量）**：0.8115 的检索缺口是答案质量的上游制约——真值块未进 context，答案要点与引用都无从谈起。拒答面（0.39/0.39）是独立的一条短路径问题（sentinel / post-generation / semantic 三形态），修复手段（拒答门控校准）与检索线互不耦合。

## 三、预注册判据（选 A 时生效；本文件批准即锁定，**不得在看到复测数字后调整**）

### 3.1 门禁指标（唯一判据，机械执行）

- **P1 检索缺口率 ≤ 0.50**：复测全量 150 例后，可答例（真值含 `acceptable_answer_points` 者，预期仍为 122）中 context∩truth=∅ 的例数占可答例的比例 **≤ 0.50**（即缺口例 ≤ 61）。
- 数值来源披露：0.50 为结构性常数（多数派门槛），与 P1.1 预注册阈值取值惯例一致；**不含依据 0.8115 基线的任何调参**。基线 0.8115 本身是既成事实，非调参对象。

### 3.2 协变指标（全量报告，不作门禁裁决）

- 答案要点修正率（三口径：机械 0.1149 / 保守 0.4195 / 修正 0.4397）；
- 拒答正确率（28 探针）与误拒率（122 可答例）——预期不变，若与基线偏离 ≥ 2 例则自动触发「拒答回归待办」软警告（不判失败，如实报告）；
- 引用契约 v2 联合分布（citation_id_validity / precision / recall / faithfulness）；
- judge 契约错误率（子集复判时）；token 实耗。

### 3.3 辅助约束（写死）

- 修复后复测的生成与 judge 协议、模型、数据集、chunk_id 归一口径与 M2/M3 **完全一致**（协议版本 `al1-containment-v1` + `al2-judge-v1`，模型 `deepseek-chat`）；
- 门禁裁决只看预注册数字；报告中不出现「主观裁定通过/不通过」以外的表述。
